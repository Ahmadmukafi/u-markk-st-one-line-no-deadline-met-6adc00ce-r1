Entry for the make.fun bounty **One Line, No Deadline Met**: a program that writes
one single-line joke giving an excuse for missing a deadline to `/output/entry.txt`.

The line:

> I missed the deadline because my calendar was still set to 2027, where I am technically early.

One sentence, 94 characters, punch at the very end — the wrong-year calendar, not a
dog-ate-it retread.
